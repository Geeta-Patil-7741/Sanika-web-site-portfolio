# Personal Portfolio Website

## Portfolio Task - 3 (Mini Project - 1)

This project is a personal portfolio website created using HTML and CSS.

The website presents my personal information, education, technical skills,
academic/personal projects and contact information.

---

## Features

- Responsive personal portfolio website
- Home section
- About Me section
- Education section
- Skills section
- Projects section
- Contact section
- Responsive navigation
- Attractive modern UI
- Mobile-friendly design
- Project descriptions
- Contact form
- GitHub Pages deployment ready

---

## Technologies Used

- HTML5
- CSS3
- Responsive Web Design
- Git
- GitHub
- GitHub Pages

---

## Website Sections

### 1. Home

The Home section introduces me and provides buttons to view my projects
and contact me.

### 2. About Me

The About Me section provides information about my background, interests
and career goals.

### 3. Education

The Education section displays my academic journey.

### 4. Skills

The Skills section displays my technical knowledge including:

- HTML
- CSS
- JavaScript
- C Programming
- Git & GitHub
- UI Design

### 5. Projects

The website contains three academic/personal projects:

#### Project 1 - Personal Portfolio Website

A responsive portfolio website created using HTML and CSS.

#### Project 2 - E-Commerce Website

A simple e-commerce website displaying products using HTML, CSS and
JavaScript.

#### Project 3 - College Website

A college website designed to provide information about courses,
departments, facilities and contact information.

### 6. Contact

The Contact section provides contact information and a form through which
visitors can send a message.
